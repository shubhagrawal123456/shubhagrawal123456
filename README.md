## 🧪 Selected Projects

**Scalable Travel & Hotel Booking Platform** · `Python` `Kafka` `Spark` `Redis` `PostgreSQL` `Databricks`
Aggregation pipeline that normalises inventory, availability, pricing and booking data from multiple supplier APIs into one model. Low-latency search with Redis caching, cache invalidation and supplier-failure fallback, plus an idempotent booking workflow with retries and compensating actions to prevent duplicate bookings.

**Financial Transaction & Reconciliation Data Platform** · `Python` `Kafka` `Spark` `Databricks` `Delta Lake` `SQL`
Streaming pipeline for high-volume payment events using Kafka and Spark Structured Streaming, with CDC, incremental ingestion and idempotent processing to keep historical state without full-table reprocessing. Automated reconciliation detects duplicate, missing and inconsistent transactions.
